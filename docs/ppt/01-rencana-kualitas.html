2. Lingkup produk dan proses

Wajib lulus: ganti Excel (T01), catat transaksi ke DB (T02–T03), stok real time (T04), laporan pemasukan/pengeluaran bulanan (T05/S02), gaji karyawan (T06), peran karyawan/admin (D01).

Proses: tidak ada fase tumpang tindih (KAK-W). Exit criteria tertulis. Dokumentasi, manual bergambar, garansi 3 bulan termasuk lingkup.

Di luar lingkup: hardware printer, toko daring, sertifikasi ISO organisasi.

4. Risiko, perubahan, DoD

Risiko tertinggi: gaji tidak diimplementasi (R01), stok salah (R02), laporan tidak otomatis (R03), bocor data (R04), waterfall vs change (R05).

Perubahan: CCB (PM, Designer, SQA, pemilik). Impact analysis, regresi, versi. Garansi 3 bulan: defect kritis 5 hari kerja.

Definition of Done: 100% kasus wajib dieksekusi, 0 defect kritis, deliverable D02–D05 ada. Tanpa itu produk tidak dirilis.
